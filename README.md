# 文字净化（SillyTavern 扩展）

一个轻量的 SillyTavern 文本替换扩展。只执行用户配置的确定性规则，不包含 AI 改写、模型调用或 API 配置。

## 功能

- 普通文本查找与替换，可将匹配内容替换为空以实现删除。
- 正则表达式替换，支持全局与大小写选项。
- 新消息生成后自动执行已启用规则。
- 可手动净化最新楼层。
- 规则可启用、停用、编辑、删除，并支持 JSON 导入导出。
- 替换只作用于消息 HTML 中的文本片段，不主动改写标签和属性。

## 安装

在 SillyTavern 的「扩展」→「安装扩展」中粘贴：

`https://github.com/1614130601zjs-del/no`

也可以在 Termux 中执行：

```bash
cd ~/SillyTavern/data/default-user/extensions
git clone https://github.com/1614130601zjs-del/no.git st-text-replacer
```

安装后刷新酒馆页面，在扩展设置中找到「文字净化」。

## 使用

1. 打开扩展设置，启用「自动净化」。
2. 点击「添加规则」，填写查找内容和替换内容。
3. 如需正则，勾选「正则表达式」；留空替换内容代表删除。
4. 规则会在角色新消息写入聊天记录时执行。历史楼层可用「净化最新楼层」处理最后一条消息。

规则保存在 SillyTavern 扩展设置中，不会发送到任何外部服务。

## 说明

本扩展当前为首个可用版本。自动处理监听 SillyTavern 的 `MESSAGE_RECEIVED` 事件；消息正文以 HTML 字符串保存，因此处理器仅对标签之间的文本片段应用规则，保留 HTML 标签与属性。正则规则请谨慎设置，避免过宽匹配。
