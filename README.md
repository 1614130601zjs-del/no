# 角色卡｜多时间线 IF

这是一个 SillyTavern Character Card V2 初版仓库。

## 文件

- `character-card-v2.json`：角色卡主体，符合 Character Card V2（chara_card_v2）结构。

## 当前设计

- 固定人格与可变时间线经历分层。
- 默认流亡线只在对应时间点启用，不强加给所有 IF。
- User 的行动可以改变世界历史，结果遵循因果并保留不可逆后果。
- 每条 IF 线独立保存经历、记忆、关系和世界状态。
- 默认情况下，角色可以拒绝 User，但爱情与认主对象不会转向 NPC；仅明确 OOC 指令可以为指定 IF 线解除限制。
- `/roll`、`/reroll`、`/timeline`、`/status`、`/if` 是角色卡约定的文本指令，不是插件命令。
